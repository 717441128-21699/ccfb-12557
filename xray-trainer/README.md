# 安检X光判图培训系统

用三维模型现场生成双能X光行李图的判图考试系统。物品是带材质的三维模型，
射线按每种材质的质量衰减系数和穿过厚度累积衰减（Beer-Lambert），
高/低两档能量分别计算，按双能比值为物品染色：有机物橙、混合物绿、金属蓝、
穿不透发黑。每次出题随机摆放物品并藏入违禁品，学员无法靠背题通过。

## 四个模块

- **出题**：设定物品数量/违禁品数量/随机种子，生成预览（可显示答案框），保存到题库
- **判图考试**：从题库抽题，学员在图上点击标记可疑位置，交卷后自动判分（命中/漏报/误报）
- **错题回看**：列出有错记录，回放当时的标记（红叉）与标准答案（绿框）
- **题库管理**：题目列表、预览、删除、导出/导入 JSON

题库与考试记录存在浏览器 localStorage，无后端。

## 技术方案

- **渲染**（`src/gl/renderer.ts`）：WebGL2。透射率 `T = exp(-Σ μᵢ·tᵢ)` 中光学厚度
  `Σ μᵢ·tᵢ` 可叠加，因此对每个凸体部件做两次 draw（背面 `+μ·深度`、正面 `-μ·深度`），
  加法混合累积到 RGBA32F 纹理（R=低能、G=高能光学厚度）；最后一个全屏 pass 算
  双能透射率、比值 `r = A_low/A_high` 并伪彩色着色。40 件物品约 250 个 draw call。
- **材质表**（`src/materials.ts`）：13 种材质的双能质量衰减系数（参照 NIST XCOM 量级）、
  密度、等效原子序数。线衰减系数 `μ = (μ/ρ)·ρ`。
- **物品库**（`src/items.ts`）：25 种物品（15 普通 + 10 违禁品），每件由若干凸体部件
  （立方体/圆柱/球/噪声团块）组成，各部件带材质。
- **场景生成**（`src/scene.ts`）：种子确定性随机；抖动网格摊开物品（允许重叠遮挡），
  大件限量防止整箱穿不透；违禁品屏幕包围盒作为判图标准答案。
- **物理**（`src/physics.ts`）：衰减/光学厚度/双能分类的纯函数，供渲染与测试共用。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 构建到 dist/
npm test           # 单元测试（物理/场景/判分）
npm run verify     # 浏览器端验收（需先 build，使用本机 Edge）
```

`?selftest=1` 自检页；`?shot=1` 示例图截图页（`node scripts/screenshot.mjs` 存 demo-xray.png）。

## 验收指标（实测通过）

1. **指数衰减律**：同一材质厚度加倍，`T(2t) = T(t)²`，与查表值偏差 ≤3%。
   - CPU：13 种材质 × 双能 × 5 种厚度共 130 组，最大相对误差 ~4e-16；
   - GPU：水/铝合金/钢三种材质渲染后从帧缓冲读回光学厚度对比查表值，
     最大相对误差 ~4e-6。
2. **性能**：40 件物品的行李箱渲染 1024×1024，实测平均 <1ms（要求 ≤200ms）。
